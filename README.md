# ビオ 育毛LP テンプレート 🧬

各院の育毛ランディングページ（LP）を **量産** するためのテンプレートです。
院ごとに変わる情報はすべて `{{トークン}}` になっています。**このトークンを実際の値に置換するだけ**で新しい院のLPが完成します。

> デザイン・構成・写真・本文コピーは全院共通。触るのは下の「差し替えチェックリスト」の値だけです。

---

## 🚀 新しい院のLPを作る手順

1. **このリポジトリ上部の緑ボタン「Use this template」→「Create a new repository」**
   - リポジトリ名は `bio-ikumou-lp-<院名ローマ字>`（例: `bio-ikumou-lp-okazaki`）
   - Public にする（GitHub Pages 無料公開のため）
2. できた新リポジトリで、下表のトークンを実際の値に**全置換**する（対象は `index.html` と `js/script.js` の2ファイル）
   - 💡 **ラクな方法**: リポジトリ画面でキーボードの `.`（ドット）を押すと VS Code 風エディタ（github.dev）が開きます。左の検索（🔍）で各 `{{TOKEN}}` を検索→「すべて置換」すると一括で直せます。
3. **Settings → Pages → Source: Deploy from branch → `main` / `(root)` → Save**
   - 数十秒で `https://biogroup810.github.io/bio-ikumou-lp-<院名>/` に公開されます
4. 完了！ 表示を確認して微調整。

> **もっとラクにしたい時は Claude に丸投げでOK。**
> 「〇〇院のLPを作って。院名=ビオ整体院〇〇院、市=〇〇市、住所=…、アクセス=…、営業時間=…、定休日=…、LINE=…」
> と伝えれば、リポジトリ作成〜置換〜公開まで自動でやります。

## ⚠️ 注意点

- **系列院一覧（「東海地方に◯店舗」セクション）は全院共通なので置換不要**・そのまま残します。新しい院を一覧に載せたい時だけ、そのブロックに1行追記してください。
- **「国家資格保持者による施術」表記について**：`{{BRAND}}` を「ビオ**接骨院**」にする院（＝柔道整復師＝国家資格者が在籍）はこの表記でOK。「ビオ**整体院**」で国家資格者が在籍しない院では、この一文（`<title>` / meta description / REASON①）を削除・修正してください（景表法・薬機法の観点）。
- **写真** は全院共通のものを `images/bio/` に同梱済み。院独自の写真がある場合は該当ファイルを同名で差し替えればOK。
- `.nojekyll` はGitHub Pages用の必須ファイルです。消さないでください。
